# Input data

The analysis runner expects the following files by default:

- All_185_clones_no_vector_no_primer_plus_consensus_renamed.fasta
- all_patients_NFLG_with_HXB2_original.fasta

Place authorized input files in this directory, or provide alternative paths using:

INPUT_FASTA=/path/to/input.fasta
HXB2_SOURCE=/path/to/hxb2_source.fasta

Patient-derived sequence data should only be distributed according to the applicable data-sharing requirements.
