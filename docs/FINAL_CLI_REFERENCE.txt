01_prepare_patient_alignments_help.txt
================================================================================
usage: 01_prepare_patient_alignments.py [-h] --input-fasta INPUT_FASTA
                                        --hxb2-source HXB2_SOURCE
                                        --output-dir OUTPUT_DIR
                                        [--threads THREADS] [--mafft MAFFT]
                                        [--allow-missing-consensus ALLOW_MISSING_CONSENSUS]

Prepare independent patient-specific HIV-1 clone alignments.

options:
  -h, --help            show this help message and exit
  --input-fasta INPUT_FASTA
                        Combined FASTA containing patient clones and optional
                        manual consensuses.
  --hxb2-source HXB2_SOURCE
                        FASTA containing the HXB2 reference sequence.
  --output-dir OUTPUT_DIR
                        Output directory.
  --threads THREADS     Number of MAFFT threads. Default: -1 (automatic/all
                        available).
  --mafft MAFFT         MAFFT executable. Default: mafft
  --allow-missing-consensus ALLOW_MISSING_CONSENSUS
                        Patient allowed to lack a supplied manual consensus.
                        May be specified multiple times.
